# Plot 5A: Evolution of Orbital Uncertainty

This plot illustrates the scientific process of **Orbit Determination**—how our knowledge of 3I/ATLAS's path becomes more precise as more observations are collected.

## What the Plot Shows
- **Shaded Region (Blue):** The 1-sigma uncertainty in the estimate of the closest approach (perijove) distance to Jupiter.
- **Solid Line:** The "Best-Fit" value calculated by astronomers at each point in time.
- **Horizontal Line:** The Jupiter Hill Radius reference.

## Key Takeaway
The plot shows that early after discovery, the uncertainty was large enough that it was "possible" the object would miss the Hill sphere entirely. However, within months of tracking, the uncertainty "collapsed" onto a value that confirms a deep encounter with Jupiter is a statistical certainty. This validates that the 3I/ATLAS Jupiter pass is a "real" physical event, not a measurement artifact.
