# Plot 1D: Penetration of Significant Radii

This bar plot provides a definitive "likelihood check" by showing the percentage of trajectories that penetrate specific significant zones around Jupiter.

## What the Plot Shows
For the population of objects passing within 100 million km of Jupiter (the "100% baseline"), this plot shows what percentage reaches the following:

- **L3 / L4 / L5**: 100% (as they are part of the broader orbital neighborhood).
- **L1 / Hill Radius / L2**: Roughly **50%** of passing objects enter this deep gravitational zone.
- **Galilean Moon Orbits**: A much smaller fraction (~0.1-1%) passes through the inner moon system.
- **Jupiter Surface**: Extremely rare events.

## Key Takeaway
Passing through the **Hill Radius** is actually a **50/50 event** for any object that is already passing through Jupiter's local orbital space. This severely demystifies the idea that 3I/ATLAS was "aimed" at the Hill radius specifically—it is one of the most likely outcomes for a near-Jupiter trajectory.
