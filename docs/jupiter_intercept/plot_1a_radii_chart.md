# Plot 1A: The Radar Chart of Meaningful Radii

This plot provides a visual context for the close approach of the interstellar object 3I/ATLAS to Jupiter. It demonstrates that Jupiter's gravitational influence is surrounded by multiple significant boundaries, from the inner moon system to the far-reaching Lagrange points.

## What the Plot Shows

The plot is a polar chart with Jupiter at the center. The radial axis uses a logarithmic scale to show both the inner moons and the vast extent of the Hill sphere and Lagrange points.

### Key Radii Mapped:
- **Roche limit (0.18M km):** The tidal destruction boundary.
- **Io, Europa, Ganymede, Callisto Orbits:** The inner "miniature solar system" of the Galilean moons.
- **L1 Point (52M km):** The Lagrange point between the Sun and Jupiter.
- **Hill radius (53.5M km):** The boundary of Jupiter's gravitational dominance.
- **L2 Point (54M km):** The Lagrange point on the opposite side of Jupiter from the Sun.
- **L4/L5 Points (778M km):** The stable "Trojan" and "Greek" points in Jupiter's orbit.
- **L3 Point (1560M km):** The point opposite Jupiter in its orbit around the Sun.

The trajectory of **3I/ATLAS** is shown as a dashed line passing near the L1/Hill/L2 complex.

## Key Takeaway
Any object entering the Jupiter system will inevitably pass near one or more of these "mathematically significant" points. By plotting the Lagrange points alongside the Hill radius, we show that the 3I/ATLAS perijove is not a unique or isolated target, but rather sits within a well-defined complex of gravitational equilibrium points.
